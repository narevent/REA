Writing

N
start or stop writing notes (note input) at the selection
A – G
write that note at the cursor, in the octave nearest the last one (H is B too)
Shift + A – G
add that note to the chord
Alt + 2 – 9
add the interval above the chord's top note
1 – 7
note value: 3 is a sixteenth, 4 an eighth, 5 a quarter, 6 a half, 7 a whole
.
dot the value (twice for a double dot)
0
a rest
+
tie: in note input, a tied note after the last; otherwise ties the selection
Ctrl + Alt + 1 – 4
write in voice 1–4, or move the selection there
Backspace
in note input, rub out what was just written

Changing

↑ ↓
a semitone up / down, spelled for the key
Ctrl + ↑ ↓
an octave
Alt + Shift + ↑ ↓
a step within the key
A – G
outside note input, re-pitch the selected note
Delete
turn the selection into rests (or, with one note of a chord picked, remove that note)
J
respell enharmonically: C♯ ↔ D♭, E ↔ F♭
S
slur from the first to the last selected note
< >
crescendo / diminuendo over the selection
Ctrl + C, Ctrl + V
copy a run of notes, paste it over the music at the selection
Ctrl + Z, Ctrl + Shift + Z
undo, redo

Measures and moving about

← →
previous / next note (in note input, moves the cursor)
Ctrl + ← →
previous / next measure
Ctrl + B
add a measure at the end
Insert
insert a measure before the selection
Ctrl + Delete
delete the selected measures
Space
play from the selection, or stop
Ctrl + S
save

Other notation programs

Import… reads a score exported from MuseScore, Sibelius, Finale or Dorico as MusicXML (.musicxml, .xml or the compressed .mxl). Export writes one back. Notes, chords, voices, ties, slurs, dynamics, hairpins, articulations, repeats, endings and jumps travel; lyrics, grace notes and layout do not.

Phrases

Select the first and the last note of a phrase (click one, Shift+click the other) and press New phrase in the Phrases panel. A phrase is played to students as one piece — everything sounding in every part between those two notes.
