Writing notes

c d e f g a h
write that note at the caret (h is B natural)
0
write a rest
2 – 7
note value: 2 is a thirty-second, 4 an eighth, 5 a quarter, 7 a whole
← →
move the caret, selecting the note it sits after
Backspace
rub out the note before the caret
Delete
delete what is selected
Esc
drop the selection
Tuplets
select the notes, then press 3, 5, 6 or 7 in the toolbar — as many notes as the tuplet has, or a multiple of it

Changing notes

↑ ↓
raise / lower by a semitone, respelled for the key
⌘/Ctrl + ↑ ↓
by an octave
Alt + Shift + ↑ ↓
by a step within the key
# b n
sharp, flat, or back to whatever the key signature says
Alt + ↑ ↓
cycle the accidental: natural, ♯, ♭, 𝄪, naturalised
r
turn the note into a rest, and back
Shift + R
repeat the selected note after itself
k
let the note follow the key signature
Alt + ← →
move the note itself, across bars if need be
, .
sound the note earlier / later — the playback offset (Shift for bigger steps)
Alt + , .
draw the note further left / right — the visual offset; when it sounds does not change
- =
quieter / louder

Getting about

⌘/Ctrl + ← →
previous / next bar ([ and ] do the same)
Enter
add a bar after the selection
Space
play the exercise — with Shift, just this bar
⌘/Ctrl + Z
undo (with Shift, redo)
⌘/Ctrl + S
save, replacing this exercise
⌘/Ctrl + Shift + S
save as a new exercise, leaving this one alone

Mouse

Click empty staff
write a note at that pitch
Click a note
select it — Shift extends, ⌘/Ctrl adds one
Right-click a note
its properties, at the cursor
Drag a note
up or down to change its pitch, left or right to move it along the bar — whichever way you start decides which
Alt + drag
sideways to change when it sounds — the playback offset
Alt + Shift + drag
sideways to change where it is drawn — the visual offset
Shift + click staff
select the bar
