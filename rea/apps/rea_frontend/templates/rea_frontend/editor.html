Save or Save as…

Save ⌘/Ctrl S
replaces the exercise that is open. Students practising it get the new version straight away.
Save as… ⌘/Ctrl ⇧ S
makes a new exercise and leaves the open one alone. You choose Where it goes: a practice module, the Drafts, or Dictation.

The one rule to know

Practice shows one exercise per module, per key (and per part, for harmonic modules). An exercise filed next to one that is already there is saved and stays in the library, but students will not see it.

Putting an exercise into a module

  1. To change what students practise — in the library on the left, open the module's exercise for that key, make your changes, and press Save.
  2. Melodic modules (Octave, Dominant, Scale — Diatonic or Alterations) — press Save as…, pick the module under Where it goes, and choose a Key that has no exercise there yet. The module sets the variant itself.
  3. Harmonic modules (Formula, Intervals, Triads, Seventh chords) — first set a new Part in the Exercise tab on the right (e.g. 4), then Save as… into the module. It appears as “Part 4” in the module's part chooser.
  4. Absolute modules — the Exercise number (1–10) is which of the ten practice exercises it is used for, within its part.

Drafts and Dictation

Drafts are only for you — students never see them. Dictation puts the exercise in the students' Dictation area. Teachers save to these two; filing into the curriculum itself is for administrators.

Writing notes

c d e f g a h
write that note at the caret (h is B natural)
0
write a rest
2 – 7
note value: 2 is a thirty-second, 4 an eighth, 5 a quarter, 7 a whole
← →
move the caret, selecting the note it sits after
Backspace
rub out the note before the caret
Delete
delete what is selected
Esc
drop the selection
Tuplets
select a note and press 3, 5, 6 or 7 in the toolbar to divide it into that many, in the time it already takes; select a run that is already the right length — three notes for a triplet, or six for two — to mark those instead

Changing notes

↑ ↓
raise / lower by a semitone, respelled for the key
⌘/Ctrl + ↑ ↓
by an octave
Alt + Shift + ↑ ↓
by a step within the key
# b n
sharp, flat, or back to whatever the key signature says
Alt + ↑ ↓
cycle the accidental: as written, 𝄪, ♯, ♭, 𝄫, naturalised
r
turn the note into a rest, and back
Shift + R
repeat the selected note after itself
k
let the note follow the key signature
Alt + ← →
move the note itself, across bars if need be
, .
sound the note earlier / later — the playback offset (Shift for bigger steps)
Alt + , .
draw the note further left / right — the visual offset; when it sounds does not change
- =
quieter / louder

Getting about

Mouse

Click empty staff

Right-click a notehead

Right-click a bar

Drag a note

Alt + drag

Alt + Shift + drag
